# MikUwU Theme for Clash Verge Rev

适用于Clash Verge Rev的自定义CSS主题，受[MikuRay](https://github.com/HatsuneMikuUwU/MikuRay/)启发

包含完整的Material Design 3视觉设计和定制化Clash Verge徽标

本主题完全基于原版预留接口开发，无需修改应用程序，兼容性强。

# 使用

1. 将cvr-theme-mikuwu.css中的内容添加到Clash Verge Rev主题设置中的自定义CSS中
2. 将如下配色添加到主题设置中

> 主要颜色：29847D
> 
> 次要颜色：607994
> 
> 主要文本颜色：161D1C(浅)/DDE4E2(深)
> 
> 次要文本颜色：3F4947(浅)/BEC9C6(深)
> 
> 信息颜色：3A7E9E
> 
> 警告颜色：A36A30
> 
> 错误颜色：DE3730
> 
> 成功颜色：43845F
>
> 文本颜色只能选择一个，如果要使用"跟随系统"配色模式，则不建议修改文本颜色
